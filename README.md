# 平台与微信小程序开发工作流

这个仓库保存一份可由 Codex 读取的 Skill 和一份可直接复制的启动 Prompt，适用于网页管理系统、微信小程序及两端联动项目。

- [SKILL.md](SKILL.md) 是长期执行准则。在 Codex 中指向本目录并调用 `platform-miniapp-delivery`。
- [PROMPT.md](PROMPT.md) 是新项目的启动模板。替换方括号中的项目路径、用户、部署条件后发送给开发代理。
- [原始命令.md](原始命令.md) 保留首次提出的设计与开发要求，以便核对模板是否漏项。

每个项目以当次设计文档和用户要求为准。仓库只含通用工作流，不含账号、密钥、私有数据或具体项目的部署配置。
